# Saisie manuelle

**Temps estimé :** 0 min · **Toujours disponible** · **Rien à connecter.**

La saisie manuelle sert aux chiffres qu'aucune source ne fournit : abonnés aux réseaux sociaux, demandes de support reçues par un autre canal, etc. Vous entrez la valeur vous-même, jour par jour.

## Ce que ça débloque

- Tout indicateur saisi à la main sur la page d'un projet.

## Étapes

1. Ouvrez un projet, puis créez un indicateur avec la source **« Saisie à la main »** (ou « Saisie manuelle » dans le catalogue).
2. Sur la page du projet, entrez la **valeur du jour** sur la carte de l'indicateur, puis cliquez sur **Enregistrer**.
3. Recommencez chaque jour, ou à la fréquence utile.
4. Un agent autorisé en écriture peut aussi enregistrer une valeur avec l'outil MCP `indicator_record`.

## Ce que vous voyez

- La carte « Saisie manuelle » est marquée **« Intégré »** : aucun test, aucun formulaire de connexion.
- Tant qu'aucune valeur n'est saisie sur la période, la carte affiche « Aucune valeur saisie sur la période. »

## Problèmes fréquents

| Symptôme | Cause probable | Action |
|---|---|---|
| La valeur n'apparaît pas | Période affichée qui ne couvre pas la date saisie. | Élargissez la période du projet. |
| Impossible de saisir | Session non administrateur, ou instance en mode DEMO. | Connectez-vous en administrateur ; en DEMO, l'écriture est désactivée. |
| Chiffre écrasé | Une nouvelle saisie remplace la valeur du même jour. | Une seule valeur par jour : corrigez en ressaisissant. |

## Limites et sécurité

- **Aucun relevé automatique** : sans saisie, aucune valeur. L'historique n'est pas reconstitué.
- Une valeur par jour et par indicateur ; la dernière saisie fait foi.
- Aucune donnée n'est envoyée à un tiers.
- Pour arrêter : supprimez l'indicateur, ou laissez-le sans nouvelle saisie.
